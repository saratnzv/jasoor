# جسور | JASOOR

پروژه‌ی وب‌اپلیکیشن پادکست‌های ایرانی برای درس مهندسی اینترنت.

## شعار برند
«آدم‌ها نه از طریق شغلشون و درسشون و کارایی که کردن، بلکه از طریق جسارت‌هایی که به خرج دادن باید تعریف بشن.»

## فناوری‌های نسخه‌ی اولیه
- HTML5
- CSS3 (RTL و responsive)
- JavaScript خالص
- داده‌های نمونه‌ی فرانت‌اند

## اجرای پروژه
فایل `index.html` را در مرورگر باز کنید. برای تجربه بهتر می‌توان از افزونه Live Server در VS Code استفاده کرد.

## ساختار
- `index.html`: صفحه‌ی اصلی شامل هدر، Hero، دسته‌بندی‌ها، اپیزودهای تازه، کارت‌های پادکست و دعوت به همکاری
- `css/style.css`: استایل‌ها و طراحی واکنش‌گرا
- `js/script.js`: داده‌های نمونه و تعاملات اولیه
- `pages/`: محل توسعه صفحات داخلی
- `assets/`: محل فایل‌های رسانه‌ای و فونت‌های محلی

## نکات امنیتی
- این نسخه فقط فرانت‌اند و داده‌های نمونه است؛ هیچ رمز عبور، کلید API، توکن یا اطلاعات محرمانه در کد قرار نگرفته.
- فایل `.env` یا اطلاعات دسترسی را هرگز به Git اضافه نکنید.
- اطلاعات فرم‌های ورود/ثبت‌نام هنوز به بک‌اند وصل نیستند.
- برای داده‌های واقعی، API و احراز هویت امن در سمت سرور پیاده‌سازی می‌شود.
- از آنجا که مخزن برای پروژه‌ی دانشگاهی است، پیشنهاد می‌شود ابتدا به صورت **Private** ساخته شود و پس از پاک‌سازی اطلاعات حساس در صورت نیاز Public شود.
