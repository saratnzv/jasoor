# جسور | JASOOR

پروژه‌ی وب‌اپلیکیشن پادکست‌های ایرانی برای درس مهندسی اینترنت.

## شعار برند
«آدم‌ها نه از طریق شغلشون و درسشون و کارایی که کردن، بلکه از طریق جسارت‌هایی که به خرج دادن باید شناخته بشن.»

## فناوری‌های نسخه‌ی اولیه
- HTML5
- CSS3 (RTL و responsive)
- JavaScript خالص
- داده‌های نمونه‌ی فرانت‌اند

## اجرای پروژه
فایل `index.html` را در مرورگر باز کنید. برای تجربه بهتر می‌توان از افزونه Live Server در VS Code استفاده کرد.

## ساختار
- `index.html`: صفحه‌ی اصلی (هدر، معرفی، دسته‌بندی‌ها، کارت پادکست‌ها، پخش‌کننده‌ی کست‌باکس، دعوت به همکاری)
- `css/style.css`: استایل‌های اصلی و واکنش‌گرا
- `css/pages.css`: استایل صفحات داخلی (فیلتر، ورود و ثبت‌نام)
- `js/main.js`: منوی موبایل
- `js/data.js`: داده‌ی مشترک پادکست‌ها و دسته‌بندی‌ها
- `js/podcasts.js`: فیلتر و جست‌وجوی صفحه‌ی پادکست‌ها
- `js/forms.js`: اعتبارسنجی فرم‌های ورود و ثبت‌نام
- `pages/podcasts.html`، `pages/login.html`، `pages/register.html`: صفحات داخلی
- `assets/images/`: لوگو و کاور پادکست‌ها

## افزودن پادکست جدید
کارت را در `index.html` اضافه کنید و همان پادکست را در آرایه‌ی `PODCASTS` در `js/data.js` هم بنویسید (شناسه‌ی کست‌باکس و `category` از روی `slug` دسته‌بندی‌ها).

## نکات امنیتی
- این نسخه فقط فرانت‌اند و داده‌های نمونه است؛ هیچ رمز عبور، کلید API، توکن یا اطلاعات محرمانه در کد قرار نگرفته.
- فایل `.env` یا اطلاعات دسترسی را هرگز به Git اضافه نکنید.
- اطلاعات فرم‌های ورود/ثبت‌نام هنوز به بک‌اند وصل نیستند.
- برای داده‌های واقعی، API و احراز هویت امن در سمت سرور پیاده‌سازی می‌شود.
- از آنجا که مخزن برای پروژه‌ی دانشگاهی است، پیشنهاد می‌شود ابتدا به صورت **Private** ساخته شود و پس از پاک‌سازی اطلاعات حساس در صورت نیاز Public شود.
